Supervised Learning

Linear, logistic, ridge, and LASSO regression, compressed sensing, support vector machines, decision trees, and random forests.

3.1 Linear Regression

Definition 3.1 (Linear Regression) Linear regression predicts a real target \(y\) from \(x\in\mathbb R^d\) with \(f_{w,b}(x)=w^\top x+b\). Ordinary least squares fits the model by minimizing the sum of squared losses.

\[ L(f,x_i,y_i)=\frac12\bigl(f(x_i)-y_i\bigr)^2. \]

  • Absorb \(b\) into \(w\) by appending a constant 1 to \(x\).
  • Exact minimizer, when \(X^\top X\) is invertible:

\[ w^*=(X^\top X)^{-1}X^\top y. \]

  • Requires matrix inversion; alternatively, use gradient descent.

3.1.1 Perceptron

Definition 3.2 (Perceptron) A perceptron is a binary linear classifier with prediction \(f(x)=\operatorname{sign}(w^\top x)\), with the bias absorbed into \(w\).

  • The hard sign output cannot be optimized directly with ordinary gradient descent.
  • Let \(P\) and \(N\) be the positive and negative training examples:
initialize w randomly
repeat until all examples are classified correctly:
    pick a random x from P union N
    if x in P and dot(w, x) < 0:
        w = w + x
    elif x in N and dot(w, x) >= 0:
        w = w - x
  • Adding \(x\) increases \(w^\top x\); subtracting \(x\) decreases it.
  • Learns only linear decision boundaries; does not converge on non-linearly separable data.

3.1.1.1 Convergence

Theorem 3.1 (Perceptron Mistake Bound) Use labels \(y_i\in\{-1,+1\}\) and initialize \(w_0=0\). Suppose there exist \(w^*\) with \(\|w^*\|=1\) and \(\gamma>0\) such that, for every \(i\),

\[ y_i\langle w^*,x_i\rangle\ge\gamma, \qquad \|x_i\|\le R. \]

Then the perceptron makes at most \(R^2/\gamma^2\) mistakes.

  • \(\gamma\) is a lower bound on the distance to the separating hyperplane; \(R\) bounds the input norms.
  • Proof sketch: Each mistake increases \(\langle w,w^*\rangle\) by at least \(\gamma\), while \(\|w\|^2\) increases by at most \(R^2\). After \(M\) mistakes:

\[ M\gamma\le\langle w_M,w^*\rangle\le\|w_M\|\le R\sqrt M \quad\Longrightarrow\quad M\le\frac{R^2}{\gamma^2}. \]

3.2 Logistic Regression

Definition 3.3 (Logistic Regression) Binary logistic regression models the probability of the positive class by applying the sigmoid to a linear score.

\[ P(y=1\mid x)=\sigma(w^\top x+b), \qquad \sigma(z)=\frac{1}{1+e^{-z}}. \]

3.2.1 Entropy and Cross-Entropy

Definition 3.4 (Entropy and Cross-Entropy) For distributions \(y\) and \(p\) on the same outcomes, entropy measures uncertainty as the ideal expected encoding length for \(y\). Cross-entropy is the expected length when using \(p\) to encode outcomes from \(y\).

\[ H(y)=-\sum_{i:\,y_i>0} y_i\log y_i, \qquad \mathrm{XE}(y,p)=-\sum_{i:\,y_i>0} y_i\log p_i. \]

3.2.2 KL Divergence

Definition 3.5 (KL Divergence) \[ D_{\mathrm{KL}}(y\|p)=\sum_{i:\,y_i>0} y_i\log\frac{y_i}{p_i} =\mathrm{XE}(y,p)-H(y). \]

  • \(D_{\mathrm{KL}}(y\|p)\ge0\), so \(\mathrm{XE}(y,p)\ge H(y)\). Equality holds exactly when \(y=p\).
  • For fixed \(y\), minimizing cross-entropy also minimizes KL divergence, making it a useful loss function.
  • KL divergence and cross-entropy are asymmetric.

3.2.3 Representation Learning

  • Deep learning is also called representation learning because it learns features automatically.
  • The learned features are commonly passed to a final linear regression/classification layer.

3.3 Ridge Regression

Definition 3.6 (Ridge Regression) Ridge regression fits a linear model with a squared \(\ell_2\) penalty on the weights, where \(\lambda\ge0\).

\[ \min_w\frac{1}{2N}\sum_i(w^\top x_i-y_i)^2 +\frac{\lambda}{2}\|w\|_2^2. \]

  • The penalty corresponds to bounding the weight norm for an appropriate choice of \(c\), which helps reduce overfitting:

\[ \min_w\frac{1}{2N}\sum_i(w^\top x_i-y_i)^2 \quad\text{subject to}\quad\|w\|_2^2\le c. \]

  • \(\lambda=0\) gives no penalty; increasing \(\lambda\) shrinks the optimal weight norm. As \(\lambda\to\infty\), \(w\to0\).
  • Update in two parts: a gradient step on the loss, then a shrink of the weights:

\[ \begin{aligned} \widehat w_{t+1}&=w_t-\frac{\eta}{N}\sum_i(w_t^\top x_i-y_i)\,x_i, \\ w_{t+1}&=(1-\eta\lambda)\,\widehat w_{t+1}. \end{aligned} \]

3.4 LASSO Regression

Definition 3.7 (LASSO Regression) LASSO regression fits a linear model with an \(\ell_1\) penalty on the weights, where \(\lambda\ge0\).

\[ \min_w\frac{1}{2N}\sum_i(w^\top x_i-y_i)^2+\lambda\|w\|_1. \]

  • The convex \(\ell_1\) penalty encourages sparse weights for feature selection. Directly constraining the number of nonzero weights with \(\|w\|_0\le c\) is hard to optimize.
  • Update in two parts: the same gradient step as linear regression, then a threshold on every coordinate \(j\):

\[ \widehat w_{t+1}=w_t-\frac{\eta}{N}\sum_i(w_t^\top x_i-y_i)\,x_i, \]

\[ (w_{t+1})_j= \begin{cases} (\widehat w_{t+1})_j-\eta\lambda & \text{if } (\widehat w_{t+1})_j>\eta\lambda,\\ (\widehat w_{t+1})_j+\eta\lambda & \text{if } (\widehat w_{t+1})_j<-\eta\lambda,\\ 0 & \text{if } (\widehat w_{t+1})_j\in[-\eta\lambda,\eta\lambda]. \end{cases} \]

  • Essentially: pulling to 0

3.5 Compressed Sensing

3.5.1 Sparsity Assumption

Definition 3.8 (Sparsity) A vector \(x\in\mathbb R^n\) is \(k\)-sparse if \(\|x\|_0\le k\), where \(\|x\|_0\) counts its nonzero entries.

  • For \(k\ll n\) and suitable \(A\), sparsity enables recovery from \(m\ll n\) measurements \(y=Ax\).

3.5.2 Restricted Isometry Property (RIP)

Definition 3.9 (Restricted Isometry Property) A matrix \(W\in\mathbb R^{n\times d}\) with \(n<d\) is \((\epsilon,s)\)-RIP if, for every \(s\)-sparse \(x\in\mathbb R^d\),

\[ (1-\epsilon)\|x\|_2^2\le\|Wx\|_2^2\le(1+\epsilon)\|x\|_2^2. \]

  • Thus, \(W\) approximately preserves the lengths of sparse vectors.
  • Without sparsity condition, this is impossible.

Theorem 3.2 (Sparse Recovery via RIP) Let \(W\) be \((\epsilon,2s)\)-RIP with \(0\le\epsilon<1\). If \(\|x\|_0\le s\) and \(y=Wx\), then

\[ \widetilde x\in\arg\min_{v:\,Wv=y}\|v\|_0 \quad\Longrightarrow\quad\widetilde x=x. \]

  • Thus, \(x\) is the unique \(s\)-sparse solution to \(Wv=y\).
  • Proof: \(h=\widetilde x-x\) is \(2s\)-sparse and \(Wh=0\). RIP gives \((1-\epsilon)\|h\|_2^2\le0\), hence \(h=0\).


Theorem 3.3 (Exact Recovery via ℓ1 Minimization) Let \(W\) be \((\epsilon,2s)\)-RIP with \(0\le\epsilon<\frac{1}{1+\sqrt2}\). If \(\|x\|_0\le s\) and \(y=Wx\), then

\[ \arg\min_{v:\,Wv=y}\|v\|_0 =\arg\min_{v:\,Wv=y}\|v\|_1 =\{x\}. \]

  • Thus, convex \(\ell_1\) minimization recovers the same unique solution as \(\ell_0\) minimization.


Theorem 3.4 (Recovery of Approximately Sparse Signals) Let \(W\) be \((\epsilon,2s)\)-RIP with \(0\le\epsilon<\frac{1}{1+\sqrt2}\). For arbitrary \(x\), let \(x_s\) retain its \(s\) largest entries in magnitude (zero elsewhere). With \(y=Wx\), reconstruct

\[ x^*\in\arg\min_{v:\,Wv=y}\|v\|_1. \]

Then, with \(\rho=\frac{\sqrt2\epsilon}{1-\epsilon}<1\),

\[ \|x^*-x\|_2\le\frac{2(1+\rho)}{(1-\rho)\sqrt s}\|x-x_s\|_1. \]

  • Recovery error is controlled by the non-sparse tail; \(x=x_s\) gives exact recovery.


Theorem 3.5 (Random Gaussian Matrix Is RIP) Let \(\epsilon,\delta\in(0,1)\), let \(s\in[d]\), and let \(n\) be an integer satisfying

\[ n\ge 216\,\frac{s\log\!\left(\dfrac{120d}{\delta\epsilon}\right)}{\epsilon^2}. \]

If \(W\in\mathbb R^{n\times d}\) has i.i.d. entries \(W_{ij}\sim\mathcal N(0,1/n)\), then with probability at least \(1-\delta\), \(W\) is \((\epsilon,s)\)-RIP.

  • Thus, the required number of measurements \(n\) grows linearly with sparsity \(s\) and only logarithmically with ambient dimension \(d\).
  • Orthogonal invariance. For any orthonormal \(U\), each row \(A_i=W_iU\) remains Gaussian with mean \(0\) and covariance \(U^\top\operatorname{Cov}(W_i^\top)U=\frac1n I\), so \(WU\) still has i.i.d. \(\mathcal N(0,1/n)\) entries and is still \((\epsilon,s)\)-RIP.
  • Transform sparsity. Even if \(x\) is not sparse itself, if \(x=Ua\) is sparse in an orthonormal basis \(U\) (e.g., Fourier or wavelet), then \(y=Wx=(WU)a\) can still be recovered via \(\ell_1\) minimization without knowing \(U\) when choosing \(W\).

3.5.3 Generative Models

Definition 3.10 (Generative Model) In compressed sensing, a generative model represents candidate signals as \(G(z)\) for a map \(G\colon\mathbb R^k\to\mathbb R^n\). The latent vector \(z\) typically has far fewer coordinates than the output signal.

Theorem 3.6 (Recovery with a ReLU Generative Model) Suppose \(G\colon\mathbb R^k\to\mathbb R^n\) is the generator given by a \(d\)-layer ReLU network. Use \(m=O(kd\log n)\) measurements with a sensing matrix \(A\in\mathbb R^{m\times n}\) whose entries are i.i.d. \(\mathcal N(0,1/m)\).

For any signal \(x^*\in\mathbb R^n\) and noisy measurements \(y=Ax^*+\eta\), choose \(\widehat z\in\mathbb R^k\) whose measurement residual \(\|y-AG(\widehat z)\|_2\) is within \(\epsilon\) of the smallest possible residual. Then, with probability \(1-e^{-\Omega(m)}\) over the draw of \(A\),

\[ \|G(\widehat z)-x^*\|_2 \le 6\min_{z^*\in\mathbb R^k}\|G(z^*)-x^*\|_2+3\|\eta\|_2+2\epsilon. \]

  • This is Theorem 1.1 of Bora et al. (2017). Compressed Sensing using Generative Models

3.6 Support Vector Machine

A linear classifier \(\operatorname{sign}(w^\top x+b)\) with labels \(y_i\in\{-1,1\}\) that separates the two classes with the largest possible margin.

3.6.1 Hard Margin

Definition 3.11 (Hard-Margin SVM) For linearly separable examples \((x_i,y_i)\) with \(y_i\in\{-1,1\}\), the hard-margin SVM solves

\[ \begin{aligned} \min_{w,b}\quad&\|w\|_2 \\ \text{subject to}\quad&y_i(w^\top x_i+b)\ge1\ \text{ for all } i. \end{aligned} \]

  • The margin boundaries are \(w^\top x+b=\pm1\). Margin length is \(\frac{1}{\|w\|_2}\), so we want \(\|w\|_2\) small.
  • The constraint puts every example on the correct side of its boundary:

\[ w^\top x_i+b\ge1\ \text{ if } y_i=1, \qquad w^\top x_i+b\le-1\ \text{ if } y_i=-1. \]

3.6.2 Soft Margin

Definition 3.12 (Soft-Margin SVM) For examples that may not be linearly separable, the soft-margin SVM relaxes the constraints with slack variables \(\xi_i\) and a penalty \(\lambda>0\):

\[ \begin{aligned} \min_{w,b,\xi}\quad&\|w\|_2+\lambda\sum_i\xi_i \\ \text{subject to}\quad&y_i(w^\top x_i+b)\ge1-\xi_i,\quad \xi_i\ge0\ \text{ for all } i. \end{aligned} \]

  • \(\xi_i\) is how far example \(i\) falls short of the margin; violating the constraint a little is OK.
  • A larger \(\lambda\) allows less slack and moves closer to the hard margin.
  • The optimal slack is \(\xi_i=\max\bigl(0,\,1-y_i(w^\top x_i+b)\bigr)\), so soft-margin SVM is just minimizing the hinge loss with a norm penalty:

\[ \min_{w,b}\|w\|_2+\lambda\sum_i\max\bigl(0,\,1-y_i(w^\top x_i+b)\bigr). \]

3.6.3 Lagrangian Duality

Definition 3.13 (Lagrangian) For the primal problem of minimizing \(f(x)\) under the constraints \(g_i(x)\le0\), the Lagrangian is

\[ L(x,\alpha)=f(x)+\sum_i\alpha_i g_i(x),\qquad \alpha_i\ge0. \]

  • \(\max_{\alpha\ge0}L(x,\alpha)\) equals \(f(x)\) if \(x\) is feasible and \(+\infty\) otherwise, so the primal optimal value is \(p^*=\min_x\max_{\alpha\ge0}L(x,\alpha)\). The dual problem swaps the order:

\[ d^*=\max_{\alpha\ge0}\min_xL(x,\alpha). \]

Theorem 3.7 (Weak and Strong Duality) Weak duality \(d^*\le p^*\) always holds. If \(f\) and every \(g_i\) are convex and Slater’s condition holds, that is, some \(x\) has \(g_i(x)<0\) for all \(i\), then strong duality \(d^*=p^*\) holds.

  • Proof of weak duality: for feasible \(x\) and \(\alpha\ge0\), \(\min_{x'}L(x',\alpha)\le L(x,\alpha)\le f(x)\).


Theorem 3.8 (KKT Conditions) Let \(f\) and every \(g_i\) be differentiable. If strong duality holds and \(x^*\), \(\alpha^*\) are primal and dual optimal, then

\[ \begin{aligned} \nabla f(x^*)+\sum_i\alpha_i^*\nabla g_i(x^*)&=0 &&\text{(stationarity)},\\ g_i(x^*)&\le0 &&\text{(primal feasibility)},\\ \alpha_i^*&\ge0 &&\text{(dual feasibility)},\\ \alpha_i^*g_i(x^*)&=0 &&\text{(complementary slackness)}. \end{aligned} \]

Conversely, if \(f\) and every \(g_i\) are convex, any \(x^*\) and \(\alpha^*\) satisfying these conditions are primal and dual optimal.

3.6.4 Dual Form

Theorem 3.9 (Dual of the SVM) Write the norm term in Definition 3.11 and Definition 3.12 as \(\frac12\|w\|_2^2\). Both problems then have the dual

\[ \begin{aligned} \max_\alpha\quad&\sum_i\alpha_i-\frac12\sum_{i,j}\alpha_i\alpha_jy_iy_j\,x_i^\top x_j \\ \text{subject to}\quad&\sum_i\alpha_iy_i=0,\qquad \begin{cases} \alpha_i\ge0 & \text{(hard margin)},\\ 0\le\alpha_i\le\lambda & \text{(soft margin)}, \end{cases} \end{aligned} \]

and the optimal weights are \(w=\sum_i\alpha_iy_ix_i\).

  • Proof sketch: give each margin constraint a multiplier \(\alpha_i\ge0\). Stationarity in \(w\) and \(b\) gives \(w=\sum_i\alpha_iy_ix_i\) and \(\sum_i\alpha_iy_i=0\); stationarity in \(\xi_i\) gives the bound \(\alpha_i\le\lambda\).
  • Thus, the soft margin only adds the upper bound \(\lambda\) on each \(\alpha_i\).
  • Examples with \(\alpha_i>0\) are the support vectors, and the data enters only through the inner products \(x_i^\top x_j\).

3.6.5 Kernel Method

Definition 3.14 (Kernel) \(K\) is a kernel if there is a feature map \(\phi\) such that

\[ K(x,z)=\phi(x)^\top\phi(z)\ \text{ for all } x,z. \]

  • For a nonlinear boundary, run the linear SVM on the features \(\phi(x)\). The dual needs only inner products, so replace \(x_i^\top x_j\) with \(K(x_i,x_j)\), without ever computing \(\phi\).
  • Prediction needs only the kernel as well:

\[ f(x)=\operatorname{sign}\Bigl(\sum_i\alpha_iy_iK(x_i,x)+b\Bigr). \]

  • \(b\) comes from any support vector \(x_s\) on the margin, where \(y_s\bigl(w^\top\phi(x_s)+b\bigr)=1\):

\[ b=y_s-w^\top\phi(x_s)=y_s-\sum_i\alpha_iy_iK(x_i,x_s). \]

  • Polynomial kernel \((x^\top z+c)^p\): the features are all monomials of degree at most \(p\).
  • Gaussian kernel \(\exp\bigl(-\|x-z\|_2^2/(2\sigma^2)\bigr)\): similarity decays with distance, and the feature space is infinite-dimensional.

Theorem 3.10 (Mercer’s Condition) \(K\) is a kernel if and only if it is symmetric and, for every finite set of points \(x_1,\dots,x_n\), the matrix \(\bigl[K(x_i,x_j)\bigr]_{i,j}\) is positive semidefinite.

3.7 Decision Tree

Definition 3.15 (Decision Tree) A decision tree is a rooted tree whose internal nodes test features and route inputs based on the results. Each input follows a path to a leaf that predicts a class or numerical value.

  • A small tree explains each prediction through its path, making it easier to interpret than a deep neural network.
  • Trees can grow large and deep.
  • Hard routing can abruptly change the prediction when an input crosses a split threshold.
  • Deep trees can easily overfit training noise.

3.7.1 Gini Index

Definition 3.16 (Gini Index) The Gini index measures class impurity in a node. If \(p_c\) is the fraction of samples at node \(S\) belonging to class \(c\) out of \(K\) classes, then

\[ I(S)=1-\sum_{c=1}^K p_c^2. \]

The index is zero when all samples belong to one class.

For a binary split into \(S_L\) and \(S_R\), choose the split with the smallest weighted child impurity

\[ \frac{|S_L|}{|S|}I(S_L)+\frac{|S_R|}{|S|}I(S_R). \]

3.8 Random Forest and Boosting

Definition 3.17 (Random Forest) A random forest is an ensemble of decision trees. Each tree trains on a bootstrap sample of the training data (drawn with replacement) and considers a random subset of features at each split. For classification, the forest picks the class with the most votes. For regression, it averages the trees’ predictions.

  • Feature bagging (Bootstrap Aggregating). At each split, sample \(m\) of the \(p\) features without replacement and choose the best split among those features. This helps decorrelate the trees and makes their combined predictions less variable.

3.8.1 Boosting Framework

Definition 3.18 (Boosting) Boosting trains weak classifiers in sequence and combines them into a final classifier.

Given training examples \((x_i,y_i)_{i=1}^m\) with \(x_i\in\mathcal X\) and \(y_i\in\{-1,+1\}\), repeat for \(t=1,\ldots,T\):

  1. Construct a distribution \(D_t\) over training indices, where \(D_t(i)\) is the weight of example \(i\).

  2. Find a weak classifier \(h_t\colon\mathcal X\to\{-1,+1\}\) with low weighted error.

    \[ \epsilon_t=\Pr_{i\sim D_t}\bigl[h_t(x_i)\ne y_i\bigr] =\sum_{i:\,h_t(x_i)\ne y_i}D_t(i). \]

After \(T\) rounds, combine \(h_1,\ldots,h_T\) into \(H_{\mathrm{final}}\), often using a weighted vote.

3.8.2 AdaBoost

Definition 3.19 (AdaBoost) AdaBoost starts with uniform sample weights \(D_1(i)=1/m\). In each round, train \(h_t\) under \(D_t\) and compute its weighted error \(\epsilon_t\). For \(0<\epsilon_t<1/2\), set

\[ \begin{aligned} \alpha_t &= \frac12\log\frac{1-\epsilon_t}{\epsilon_t}, \\ D_{t+1}(i) &= \frac{D_t(i)\exp\!\bigl(-\alpha_t y_i h_t(x_i)\bigr)}{Z_t}. \end{aligned} \]

\(Z_t\) normalizes the weights to sum to 1. The update increases the weights of misclassified examples. The final prediction is the weighted vote

\[ H_{\mathrm{final}}(x)=\operatorname{sign}\!\left(\sum_{t=1}^T\alpha_t h_t(x)\right). \]

Theorem 3.11 (AdaBoost Training Error Bound) Write the weighted error in round \(t\) as \(\epsilon_t=\tfrac12-\gamma_t\). Then the fraction of training examples misclassified by \(H_{\mathrm{final}}\) satisfies

\[ \begin{aligned} \operatorname{err}_{\mathrm{train}}(H_{\mathrm{final}}) &\le \prod_{t=1}^T 2\sqrt{\epsilon_t(1-\epsilon_t)} \\ &= \prod_{t=1}^T \sqrt{1-4\gamma_t^2} \le \exp\!\left(-2\sum_{t=1}^T\gamma_t^2\right). \end{aligned} \]

If \(\gamma_t\ge\gamma>0\) in every round, then \(\operatorname{err}_{\mathrm{train}}(H_{\mathrm{final}})\le e^{-2\gamma^2T}\).

Proof. Let \(f(x)=\sum_{t=1}^T\alpha_t h_t(x)\), so \(H_{\mathrm{final}}(x)=\operatorname{sign}(f(x))\).

Unrolling the updates from \(D_1(i)=1/m\) gives

\[ D_{T+1}(i) =\frac{e^{-y_i f(x_i)}}{m\prod_{t=1}^T Z_t}. \]

On each mistake, \(y_i f(x_i)\le0\), so the exponential loss is at least 1.

\[ \begin{aligned} \operatorname{err}_{\mathrm{train}}(H_{\mathrm{final}}) &\le\frac{1}{m}\sum_i e^{-y_i f(x_i)} \\ &=\left(\prod_{t=1}^T Z_t\right)\sum_i D_{T+1}(i) =\prod_{t=1}^T Z_t. \end{aligned} \]

To compute \(Z_t\), group the wrong and correct predictions, which contribute weights \(\epsilon_t\) and \(1-\epsilon_t\).

\[ Z_t=\epsilon_t e^{\alpha_t}+(1-\epsilon_t)e^{-\alpha_t}. \]

Setting the derivative to zero gives \(\alpha_t=\tfrac12\log((1-\epsilon_t)/\epsilon_t)\) and \(Z_t=2\sqrt{\epsilon_t(1-\epsilon_t)}\). Since \(\sqrt{1-4\gamma_t^2}\le e^{-2\gamma_t^2}\), multiplying over the rounds gives the bound.

3.8.3 Margin-Based Analysis

Definition 3.20 (Voting Margin) For the margin analysis, normalize AdaBoost’s vote as \(f(x)=\sum_t\alpha_t h_t(x)/\sum_t\alpha_t\). The margin \(yf(x)\) measures how much the weighted vote favors the true label.

Theorem 3.12 (Margin-Based Generalization Bound) Let \(S\) contain \(m\) independent examples drawn from a distribution \(D\) on \(\mathcal X\times\{-1,+1\}\). Let \(\mathcal H\) be a finite class of binary base classifiers and \(\mathcal C=\operatorname{conv}(\mathcal H)\) the class of their weighted averages. Write \(P_D\) for population probability and \(P_S\) for the fraction of training examples satisfying an event.

For \(0<\delta<1\), with probability at least \(1-\delta\) over \(S\), the following holds simultaneously for every \(f\in\mathcal C\) and every \(\theta>0\).

\[ P_D[yf(x)\le0] \le P_S[yf(x)\le\theta] +O\!\left(\sqrt{\frac{1}{m}\left( \frac{\log m\,\log|\mathcal H|}{\theta^2} +\log\frac{1}{\delta}\right)}\right). \]

  • This is Theorem 1 of Schapire et al. (1998). Boosting the Margin

Theorem 3.13 (AdaBoost Training Margin Bound) Let \(\epsilon_1,\ldots,\epsilon_T\) be the weighted training errors of the base classifiers in AdaBoost, and let \(f\) be the normalized vote above. For any threshold \(\theta\),

\[ P_S[yf(x)\le\theta] \le 2^T\prod_{t=1}^T\sqrt{\epsilon_t^{1-\theta}(1-\epsilon_t)^{1+\theta}}. \]

If \(\epsilon_t\le\tfrac12-\gamma\) in every round for some fixed \(\gamma>0\), then this upper bound decays exponentially in \(T\) whenever \(\theta<\gamma\).

Proof sketch. Let \(A_T=\sum_t\alpha_t\). If \(yf(x)\le\theta\), then \(e^{A_T(\theta-yf(x))}\ge1\). Averaging over the training set and using the weight identity from the proof of Theorem 3.11 gives

\[ P_S[yf(x)\le\theta] \le e^{\theta A_T}\frac1m\sum_i e^{-A_T y_i f(x_i)} =\prod_{t=1}^T e^{\theta\alpha_t}Z_t. \]

Substituting \(\alpha_t=\tfrac12\log((1-\epsilon_t)/\epsilon_t)\) and \(Z_t=2\sqrt{\epsilon_t(1-\epsilon_t)}\) gives the stated product.

For exponential decay, use \(Z_t=1/\cosh\alpha_t\) and \(\tanh\alpha_t=1-2\epsilon_t\ge2\gamma\). Since \(\tanh\) is concave on \([0,\infty)\),

\[ \log\cosh\alpha_t=\int_0^{\alpha_t}\tanh u\,du \ge\tfrac12\alpha_t\tanh\alpha_t\ge\gamma\alpha_t. \]

Thus \(e^{\theta\alpha_t}Z_t\le e^{-(\gamma-\theta)\alpha_t}\). Since \(\alpha_t\ge\tanh\alpha_t\ge2\gamma\), the product is at most \(e^{-2\gamma(\gamma-\theta)T}\) when \(\theta<\gamma\).

3.8.4 Gradient Boosting

3.8.4.1 AdaBoost as Coordinate Descent

Each weak learner \(g_j\) has a coefficient \(\lambda_j\), initially zero. AdaBoost reduces the average exponential loss

\[ F_\lambda(x)=\sum_j\lambda_jg_j(x), \qquad L(\lambda)=\frac{1}{m}\sum_{i=1}^m e^{-y_i F_\lambda(x_i)}. \]

Each round selects a learner \(g_j\) with low weighted error and updates one coordinate, \(\lambda_j\gets\lambda_j+\alpha_t\), by line search. After \(T\) rounds, \(L(\lambda)=\prod_{t=1}^T Z_t\) by the proof of Theorem 3.11.

3.8.4.2 Squared Loss

Definition 3.21 (Gradient Boosting) Gradient boosting adds a weak learner each round to approximate the negative loss gradient with respect to the current predictions.

Treat the training predictions \((F(x_1),\ldots,F(x_n))\) as the coordinates of a vector. For squared loss,

\[ L(Y,F)=\frac12\sum_{i=1}^n\bigl(y_i-F(x_i)\bigr)^2, \qquad r_i=-\frac{\partial L}{\partial F(x_i)}=y_i-F(x_i). \]

Adding the exact residual would give \(F(x_i)+r_i=y_i\). Fit a shallow regression tree \(h\) to the pairs \((x_i,r_i)\) to approximate that correction. Add the tree with a small learning rate \(\eta\) to damp each update.

\[ F_{\mathrm{new}}(x)=F(x)+\eta h(x). \]
